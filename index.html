Python 条件分支 · 一页学懂

if / elif / else —— 让程序学会「做决定」

写程序就像给电脑下指令。有时候你希望电脑根据情况选择走哪条路，这就是「条件分支」。

最核心的一句话：
「如果（if）某个条件成立，就做某件事；否则（else）做另一件事。」

if 条件:
    缩进里、条件成立时执行的代码
else:
    缩进里、条件不成立时执行的代码
注意冒号 : 和缩进（一般是 4 个空格）。Python 靠缩进来判断代码属于哪一块，缩进错了程序就错。

一、if / else：二选一

age = 18
if age >= 18:
    print("你是成年人")
else:
    print("你是未成年人")

把下面的 age 改成 15、20、66，点运行试试结果变化。

二、if / elif / else：多选一

当有多个分支时，用 elif（= else if）从上到下依次判断，第一个成立的就执行，其余全部跳过。

score = 85
if score >= 90:
    print("优秀")
elif score >= 80:
    print("良好")
elif score >= 60:
    print("及格")
else:
    print("不及格")
把 score 改成 95，输出还是「优秀」而不是「良好」，因为 95 >= 90 第一个就命中了，下面不看了。顺序很重要。

三、比较运算符

条件里最常用的「比较」，结果是 True 或 False：

运算符含义举例结果
==等于5 == 5True
!=不等于5 != 3True
>大于5 > 3True
<小于5 < 3False
>=大于等于5 >= 5True
<=小于等于5 <= 3False
最容易踩的坑：判断「相等」用两个等号 ==，一个等号 = 是赋值。写混了会报错或出现奇怪结果。

七、记忆口诀

  1. if 开头，冒号结尾，代码要缩进。
  2. 二选一用 else，多选一用 elif。
  3. 判断相等用 ==，赋值用 =。
  4. and 全真才真，or 一真即真，not 取反义。
  5. 条件从上往下顺序判断，命中即停。
